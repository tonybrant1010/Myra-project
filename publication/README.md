# Publikációs Anyagok

Ez a mappa a Myra Project tudományos és jogi megfelelőségéhez kapcsolódó nyilvános és hitelesített dokumentumokat tartalmazza.

## Fájlok Leírása

- **[self_audit_report.docx](self_audit_report.docx)**: A Zenodo-n publikált technikai, adatvédelmi és klinikai önértékelési jelentés Word (.docx) formátumban (kapcsolódó DOI: 10.5281/zenodo.20698359).
- **[myra_data_flow_map.png](myra_data_flow_map.png)**: Az audit jelentésben hivatkozott részletes adatfolyam- és architektúra-térkép, amely bemutatja a bejövő kérések, a biztonsági határok és a Supabase/PostgreSQL adatbázis közötti kapcsolatokat.
