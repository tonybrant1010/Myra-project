# Képernyőképek

Ide kerül a két nyilvános képernyőkép, amelyeket a fő README jelenít meg:

- `kepernyokep-1.png` — a bejelentkező képernyő (lehetőleg üres e-mail mezovel)
- `kepernyokep-2.png` — a chatfelület egy semleges, minta-beszélgetéssel

**Ne** kerüljön ide valódi felhasználói beszélgetés vagy személyes adat:
a repó nyilvános, a képek pedig a felületet mutatják be, nem a tartalmat.
Ajánlott szélesség: 860 px (a README 430 px-en jeleníti meg oket).
